🏭 工厂车间地图组件

基于Vue 3 + TypeScript + Element Plus的交互式工厂地图组件

🚀 快速访问

组件已集成到项目中，您可以通过以下方式访问：

监控中心首页 工厂地图页面

✨ 主要功能

🗺️ 区域划分

支持5个功能区域：生产区、仓储区、办公区、检测区、维护区

每个区域使用不同颜色标识，便于区分

🔧 设备管理

支持21个设备点位的实时监控

每个设备具有唯一的位置编码（如"1区3排"）

📊 状态监控

实时显示设备状态：

在线 警告 离线 错误

🖱️ 交互功能

• 点击设备查看详细信息

• 鼠标滚轮缩放地图

• 拖拽平移浏览

• 按钮控制视图

🛠️ 技术实现

前端技术栈

• Vue 3 Composition API

• TypeScript 类型安全

• Element Plus UI组件

• SVG 2D渲染

响应式设计

• 自适应不同屏幕尺寸

• 移动端友好

• 流畅的动画效果

• 现代浏览器兼容

📝 使用示例

基本使用

<template> <div class="map-container"> <FactoryMap /> </div> </template> <script setup lang="ts"> import FactoryMap from '@/components/FactoryMap.vue' </script>

设备数据结构

interface FactoryDevice { id: string // 设备唯一ID name: string // 设备名称 type: string // 设备类型 x: number // SVG坐标系中的x位置 y: number // SVG坐标系中的y位置 status: 'online' | 'offline' | 'warning' | 'error' zone: string // 所属区域ID position: string // 位置编码 parameters?: { // 可选参数 temperature?: number pressure?: number vibration?: number power?: number } }
